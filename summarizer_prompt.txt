You are given structured pathology findings in JSON.

Your task is to produce a concise summary of clinically relevant findings.

Rules:

- Return ONLY valid JSON.
- Use exactly this schema:

{
  "summary": {
  "English": [...],
  "Hindi": [...],
  "Marathi": [...]
  }
}

- Each array item must be a short, plain, and concise statement.
- Do not explain causes.
- Do not recommend treatment.
- Do not suggest consulting a doctor.
- Do not add lifestyle advice.
- Do not infer diagnoses unless directly supported by the findings.
- Ignore normal findings unless they provide useful context.
- Combine related abnormalities into a single statement when appropriate.
- Preserve severity when supported by the data (slightly, mildly, moderately, significantly, severely, extremely).
- Prefer common language over medical jargon.
- Do not mention reference ranges.
- Do not mention exact laboratory values unless necessary.
- Do not repeat the same finding in different words.
- After the English Summary, provide the translation of the summary in Hindi and Marathi.
- The Hindi and Marathi summaries should match the English summary as close as possible, only the language should be different.
- For Hindi and Marathi translations, use simple and commonly used words.
- Make sure the abbreviations are also translated in Hindi and Marathi. e.g. ALP -> एएलपी, LDL -> एलडीएल, ESR -> ईएसआर.
- Make sure the meaning of translations is the same as the English summary.
- If every finding is normal, return:

{
  "summary": {
  "English": ["No significant abnormalities were found."],
  "Hindi": ["रिपोर्ट में कोई महत्वपूर्ण असामान्यता नहीं पाई गई।"],
  "Marathi": ["अहवालात कोणतीही महत्त्वाची असामान्यता आढळली नाही."]
  }
}
